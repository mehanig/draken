03 / What it does—and doesn’t

It reads your chats.

your code.

You still choose what to do,
what to trust, and what to review.

How it’s built
01

It won’t change your projects.

It doesn’t run project commands, edit your code, start coding agents or make Git changes.

02

Keep your original logs.

Links in the summary lead back to your agent logs. If a file is missing or changed, Draken tells you. It doesn’t keep a hidden copy of the original text.

03

Some content leaves your computer.

Reading and searching logs happen locally. For summaries and text replies, pi sends content to the model provider you use. If you use voice, your audio and some history go to OpenAI.

04

Reading isn’t reviewing.

Draken won’t treat an AI suggestion as your decision, or mark work reviewed for you.

A few practical questions

Good to know.

Do I have to use voice?

No. You can read summaries, ask questions, check the original messages and save notes without a microphone. Voice is optional and has its own setup.

Will it remember everything?

No. It can only use logs it supports and sessions you’ve included. Summaries leave details out, and search can miss things. If something matters, check the original message.

Does opening the page start anything?

This page is just a demo. In Draken, opening Settings or checking setup doesn’t read your chat logs, start a summary or turn on your microphone. If you turn on background indexing, it can update search while the server runs.

What should I back up?

Your original agent logs and Draken’s saved data. Old summaries still need the original logs when you open their sources. Back up both before an upgrade. Don’t try to undo a database change by running an older version of Draken.
