A few practical questions

Good to know.

Do I have to use voice?+

No. Briefings, text discussion, source inspection and explicit notes work without a microphone. ChatGPT voice is an optional, separately configured interface.

Does “complete history” mean perfect recall?+

No. Briefing preparation accounts for the eligible evidence in your frozen snapshot, within supported source formats and safety limits. Summaries are lossy, retrieval is selective, and model claims still need review. A missing search result is not proof that something never happened.

Does opening the page start anything?+

This website is a static demonstration. In the app, opening Settings or checking setup does not scan transcripts, generate a briefing or acquire a microphone. Optional background indexing is a separate permission and runs only while the server is running.

What should I back up?+

Both your original agent logs and private Draken state. Originals remain the evidence archive, including for frozen snapshots. Back up before migrating an existing installation; launching an old binary is not a safe rollback.
